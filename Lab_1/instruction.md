级联 PID 有三个参数，每个参数的作用完全不同，按以下顺序调：

---

**第一步：清零 Ki，只调外环 Kp**

```python
self.Kp = np.array([1.0, 1.0, 0.0])
self.Ki = np.array([0.0, 0.0, 0.0])  # 先清零
self.Kd = np.array([0.0, 0.0, 0.0])  # 先清零
```

Kp 控制"飞多快"，即位置误差转换成目标速度的比例。只看无人机能不能朝目标运动：

| 现象 | 操作 |
|------|------|
| 几乎不动 | Kp × 2 |
| 能朝目标飞但很慢 | Kp × 1.5 |
| 冲过目标很远 | Kp × 0.7，同时检查 clip 范围 |

目标是**能稳定靠近目标，clip 范围 ±3.0 基本够用**，不需要完全到达。

---

**第二步：加 Kd 压制振荡**

```python
self.Kd = np.array([0.5, 0.5, 0.0])
```

Kd 控制速度误差的阻尼，防止无人机在目标附近来回振荡：

| 现象 | 操作 |
|------|------|
| 到达目标附近反复震荡 | Kd × 1.5 |
| 接近目标时越来越慢、迟钝 | Kd 太大，× 0.7 |
| 静止时有高频抖动 | 降低 alpha（增强滤波）|

Kd 调到**刚好能稳定停在目标附近不振荡**即可。

---

**第三步：加 Ki 消除风扰残差**

```python
self.Ki = np.array([1.0, 1.0, 0.0])
```

Ki 是内环的比例增益，作用在积分后的速度误差上，专门对抗常值风扰：

| 现象 | 操作 |
|------|------|
| 逆风时有稳态残差 | Ki × 2 |
| 到达后开始低频漂移 | Ki 太大，× 0.5 |
| 轨迹画弧 | Ki 不够，× 1.5 |

---

**第四步：微调 clip 范围**

如果加大 Ki 后残差还在，先看 clip 是否限制了积分：

```python
self.error_sum = np.clip(self.error_sum, -10.0, 10.0)
```

最大积分推力 = Ki × clip = `2.0 × 10 = 20`，已经很大。如果风特别强才需要放到 ±20。

---

**参数之间的关系总结：**

```
Kp 大 → 飞得快，但容易过冲
Kd 大 → 阻尼强，但静止时容易抖
Ki 大 → 抗风强，但容易低频漂移
alpha 小 → 滤波强，但速度反馈滞后，引入振荡
```

调参时**每次只动一个参数**，观察效果后再动下一个。
